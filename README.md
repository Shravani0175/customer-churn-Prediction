# Customer Churn Prediction

## About the Project
This project uses Machine Learning to predict whether a customer is likely to leave a telecommunications company.

A Random Forest classifier is trained on the Telco Customer Churn dataset to identify customer churn patterns and important factors affecting customer retention.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Models
- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier

## Project Workflow
1. Dataset loading and exploration
2. Data cleaning and preprocessing
3. Categorical data encoding
4. Train-test splitting
5. Model training
6. Model evaluation
7. Confusion matrix visualization
8. Feature importance analysis
9. Saving the trained model

## Dataset
IBM Telco Customer Churn dataset.

Source: https://www.kaggle.com/datasets/blastchar/telco-customer-churn

## Project Files
- `customer_churn_prediction.ipynb` – Complete ML workflow
- `WA_Fn-UseC_-Telco-Customer-Churn.csv` – Dataset
- `customer_churn_model.pkl` – Trained Random Forest model
- `feature_names.pkl` – Model feature names

## Objective
To understand customer churn patterns and build a machine learning model that can help businesses identify customers who may leave their services.
